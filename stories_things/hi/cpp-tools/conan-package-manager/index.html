    Conan C++ पैकेज मैनेजर की शुरुआत¶

    1. Conan इंस्टॉल करना¶

    pip3 install conan

    2. थर्ड-पार्टी लाइब्रेरी इंस्टॉल करना¶

    थर्ड-पार्टी लाइब्रेरी इंस्टॉल करते समय हमें आमतौर पर इंस्टॉल की जाने वाली लाइब्रेरी का version पता होना चाहिए, इसके लिए conan एक संबंधित search कमांड उपलब्ध कराता है जो संबंधित लाइब्रेरी के versions की सूची दिखाता है।

    conan search gtest --remote=conancenter

    अगर सीधे search करेंगे तो error आएगा, conancenter नहीं मिल पाएगा, इसलिए पहला कदम remote सेट करना है।

    conan remote add conancenter https://center.conan.io

    इसके बाद जब हम ऊपर वाला search कमांड दोबारा चलाते हैं, तो error दिखता है:

    ERROR: HTTPSConnectionPool(host='center.conan.io', port=443): Max retries exceeded with url: /v1/ping (Caused by SSLError(SSLError(1, '[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed (_ssl.c:877)'),))

Unable to connect to conancenter=https://center.conan.io
1. Make sure the remote is reachable or,
2. Disable it by using conan remote disable,
Then try again.

    अब certificate कॉन्फ़िगर करने की ज़रूरत है

    conan config install https://github.com/conan-io/conanclientcert.git

    3. एक प्रोजेक्ट लिखना¶

    आगे बढ़ते हुए, conan का उपयोग करके एक प्रोजेक्ट लिखते हैं।

    प्रोजेक्ट की पृष्ठभूमि: development चरण में हमें unit testing करने की ज़रूरत होती है, उदाहरण के लिए: division में 0 से और गैर-शून्य से भाग देने जैसे boundary cases के assertions की जांच करनी होती है, इसके लिए हमें थर्ड-पार्टी लाइब्रेरी चाहिए, यहाँ gtest का उपयोग किया गया है।

    1.कोड लिखें

    #include <gtest/gtest.h>
double divide(double a, double b) { return b == 0 ? 0 : a / b; }

TEST(Div, NonZero) {
  double expected = 1.5;
  double actual = divide(3, 2);
  ASSERT_EQ(expected, actual);
}

TEST(Div, Zero) {
  double expected = 0;
  double actual = divide(3, 0);
  ASSERT_EQ(expected, actual);
}

    2.conanfile.txt लिखें, एक gtest version निर्दिष्ट करें।

    [requires]
gtest/1.13.0

[generators]
cmake

    3.CMakeLists.txt जोड़ें, इसकी सामग्री बहुत सरल है: इसमें विस्मयादिचक चिह्न वाले हिस्सों पर ध्यान देने की ज़रूरत है।

    cmake_minimum_required(VERSION 3.16)
project(MultiplyTest LANGUAGES CXX)

enable_testing()

// !!!
find_package(GTest REQUIRED)

add_executable(div_test div_test.cpp)

// !!!
target_link_libraries(div_test
 PRIVATE
  GTest::GTest)

add_test(div_gtest div_test)
