    C++ gRPC ミニプロジェクト¶

    C++那些事のgrpc小Demo¶

    GitHub で人気の RPC には grpc、brpc があり、テンセント社内で高く評価されている trpc などもあります。これらの RPC はさまざまな言語・プラットフォームに対応しています。今回は grpc の使い方を、シンプルなデモから入って解説します。プロジェクト全体は CMake でビルドする、非常に標準的な RPC プロジェクト管理となっており、すべてのコードは星球で更新済みです。入手方法は最後の QR コードをご覧ください。

    1.Step by Step 環境¶

    もしあなたのコンピュータが mac なら、申し訳ありませんが、現時点では最新バージョンの grpc は使えません。最新バージョンの grpc は abseil を使用しており、コンパイルで問題が発生します。公式ではまだ解決されていません。解決方法をご存知の方は、コメント欄で教えてください。私のほうでは今のところ解決方法を見つけられていません。

    そのため、mac には低いバージョンの grpc をインストールするか、linux に直接インストールすることをお勧めします。linux では最新バージョンの grpc が使用でき、一度インストールすれば問題はまったくありません。

    インストール方法：

    git clone -b v1.57.0 git@github.com:grpc/grpc.git

    次に submodule を初期化します

    git submodule update --init

    cmake でビルドしてインストール：

    cd cmake
mkdir build
cd build
cmake -DgRPC_INSTALL=ON -DgRPC_BUILD_TESTS=OFF   -DCMAKE_INSTALL_PREFIX=/usr/local/grpc ../..

make -j8
make -j8 install // root 权限

    上のインストール先ディレクトリは適宜変更できます。install 時には root 権限が必要な点に注意してください。

    インストールが完了したら、bin ディレクトリを PATH に設定します。例えば：

    export PATH=/usr/local/grpc/bin:$PATH

    2.文字列反転Demo¶

    環境が整ったので、いよいよ作業に取り掛かれます。

    2.1 プロトコル¶

    最初にやるべきことは rpc プロトコルの確定です：

    syntax = "proto3";

package stringreverse;

service StringReverse {
    rpc sendRequest (StringRequest) returns (StringReply) {}
}

message StringRequest {
    string original = 1;
}

message StringReply {
    string reversed = 1;
}

    非常にシンプルなプロトコルで、文字列を 1 つリクエストし、文字列を 1 つ返します。

    2.2 クライアント¶

    rpc リクエストの文字列を構築し、sendRequest インターフェースを呼び出して送信するだけです。

    std::string str = "hello world grpc!";
std::cout << "Original string: " << str << std::endl;
StringRequest request;
StringReply reply;
ClientContext context;
request.set_original(str);
Status status = stub->sendRequest(&context, request, &reply);
if (status.ok()) {
    std::cout << "Reversed string: " << reply.reversed() << std::endl;
}
// do something

    2.3 サーバ側¶

    Service を継承して文字列反転のロジックを実装します。

    class ReverseServiceImplementation final : public StringReverse::Service {
    Status sendRequest(ServerContext* context, const StringRequest* request,
                     StringReply* reply) override {
    // 反转逻辑
  }             
}

    最後に service を登録するだけです：

    builder.RegisterService(&service);
std::unique_ptr<Server> server(builder.BuildAndStart());
std::cout << "Server listening on port: " << server_address << std::endl;
