    Introducción a Conan, gestor de paquetes de C++¶

    1. Instalación de Conan¶

    pip3 install conan

    2. Instalar bibliotecas de terceros¶

    Al instalar bibliotecas de terceros solemos necesitar conocer la versión de la biblioteca instalada; conan ofrece para ello el comando de búsqueda correspondiente, que lista las versiones de la biblioteca.

    conan search gtest --remote=conancenter

    Si buscas directamente obtendrás un error porque no encuentra conancenter, así que el primer paso es configurar el remote.

    conan remote add conancenter https://center.conan.io

    A continuación, volvemos a ejecutar el comando de búsqueda anterior y nos encontramos con este error:

    ERROR: HTTPSConnectionPool(host='center.conan.io', port=443): Max retries exceeded with url: /v1/ping (Caused by SSLError(SSLError(1, '[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed (_ssl.c:877)'),))

Unable to connect to conancenter=https://center.conan.io
1. Make sure the remote is reachable or,
2. Disable it by using conan remote disable,
Then try again.

    En este punto hay que configurar el certificado

    conan config install https://github.com/conan-io/conanclientcert.git

    Salida:

    3. Escribir un proyecto¶

    A continuación, escribimos un proyecto con conan.

    Contexto del proyecto: en la fase de desarrollo necesitamos hacer pruebas unitarias; por ejemplo, para la división hay que comprobar con aserciones los casos límite de dividir entre 0 y entre valores no nulos, para lo cual introducimos una biblioteca de terceros; aquí usamos gtest.

    1.Escribir el código

    #include <gtest/gtest.h>
double divide(double a, double b) { return b == 0 ? 0 : a / b; }

TEST(Div, NonZero) {
  double expected = 1.5;
  double actual = divide(3, 2);
  ASSERT_EQ(expected, actual);
}

TEST(Div, Zero) {
  double expected = 0;
  double actual = divide(3, 0);
  ASSERT_EQ(expected, actual);
}

    2.Escribir conanfile.txt, especificando una versión de gtest.

    [requires]
gtest/1.13.0

[generators]
cmake

    3.Añadir CMakeLists.txt; el contenido es muy sencillo: conviene prestar atención a las partes marcadas con signos de exclamación.

    cmake_minimum_required(VERSION 3.16)
project(MultiplyTest LANGUAGES CXX)

enable_testing()

// !!!
find_package(GTest REQUIRED)

add_executable(div_test div_test.cpp)

// !!!
target_link_libraries(div_test
 PRIVATE
  GTest::GTest)

add_test(div_gtest div_test)
